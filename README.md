# 火柴人格斗（Stickman Brawl）

双人同键盘对战的火柴人格斗网页游戏，纯前端单文件，打开即玩。

**在线试玩**：https://Carl-Li101008.github.io/stickman-fighter/

## 玩法

- 徒手拳击、二段跳、格挡，武器定期从天而降，捡起就用
- 武器：手枪 / 霰弹枪 / 突击步枪 / 火箭筒 / 长剑 / 重锤，没子弹还能扔出去砸人
- 枪械弹道严格水平，打不打得到全凭走位和跳台时机
- 5 张地图每回合随机轮换：城市天台 / 落日峡谷 / 幽暗森林 / 熔岩洞窟 / 极光雪原
- 先赢 3 回合获胜

## 操作

| 操作 | P1 红方 | P2 蓝方 |
|---|---|---|
| 移动 | A / D | ← / → |
| 跳跃（二段跳） | W | ↑ |
| 格挡 | S | ↓ |
| 攻击 / 开枪 | F | . |
| 拾取 / 投掷 | G | , |
| 暂停 | P | P |

## 本地运行

下载 `index.html` 双击即可，无需服务器。

## 技术

React + TypeScript + Canvas，音效为 WebAudio 实时合成，无外部资源。
