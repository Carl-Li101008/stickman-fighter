# 火柴人格斗 · 微信小游戏 导入说明

## 快速开始（无需注册，3 分钟）

1. 下载安装「微信开发者工具」稳定版：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 解压本压缩包，得到 `minigame` 文件夹
3. 打开微信开发者工具 → 导入项目 → 目录选择 `minigame`
4. AppID 选「测试号」（工程里已填 touristappid，直接确定即可）
5. 点「编译」→ 工具内即可试玩；点「预览」生成二维码，手机微信扫码真机试玩

## 用自己的 AppID

1. 访问 https://mp.weixin.qq.com 注册小程序账号（个人主体免费）
2. 注册后在「管理 → 小游戏」中创建小游戏，获得 AppID
3. 导入工程时填入自己的 AppID（或修改 `project.config.json` 里的 appid 字段）
4. 手机预览：工具栏「预览」按钮 → 微信扫码

## 操作方式（手机触屏）

- 左半屏 = P1 红方，右半屏 = P2 蓝方，同一部手机双人对战
- 摇杆：左右移动，上推跳跃（支持二段跳），下推钻下平台
- 攻键：攻击 / 开枪（水平弹道，方向 = 摇杆朝向）
- 捡键：拾取 / 投掷武器
- 右上角 II：暂停

## 分享给朋友

- 「预览」二维码发给朋友，对方用微信扫码即可玩（开发版）
- 正式发布上线需要游戏版号；无版号期间可用体验版传播（开发者工具 → 上传 → 小程序后台设置体验版，可添加体验成员）

## 内容与网页版一致

5 张随机地图（含地刺机关）、6 种武器空投、先赢 5 回合、第 6 回合起挤压模式（齿轮墙 / 岩浆上涨 / 绞肉传送带）。
